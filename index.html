概述

NeleColor 是一套用于处理.nelecolor图像格式的工具集，包含两个主要组件：

  • NeleColor - 用于查看.nelecolor格式文件
  • NeleColor 转换器 - 用于将常见图像格式转换为.nelecolor格式

这两个工具都基于Python开发，使用Tkinter构建图形界面，Pillow库处理图像数据。

提示： 使用最新版本的NeleColor可以获得最佳体验和完整功能支持。

快速入门

基本使用流程

  1. 安装Python 3.6+和Pillow库
  2. 下载并运行NeleColor工具
  3. 使用转换器将图片转为.nelecolor格式
  4. 使用查看器打开.nelecolor文件
  5. 可导出为原始格式或进行简单编辑

.nelecolor 格式规范

.nelecolor 是一种简单的二进制图像格式，由两部分组成：

  1. 文本头 - 包含分辨率信息和原始格式
  2. 像素数据 - 连续的RGB值二进制数据

文件头格式

文件头是一个UTF-8编码的字符串，格式为：宽度x高度.扩展名[:编码]

例如：

  • 256x256.png - 256x256像素的图像，原始格式为PNG，默认RGB编码
  • 300x200.jpg:rgba - 300x200像素，原始格式JPG，使用RGBA编码

文件头以换行符(\n)结束

像素数据格式

像素数据是连续的二进制数据，支持两种格式：

  • RGB: 每个像素由3个字节表示(RGB)
  • RGBA: 每个像素由4个字节表示(RGBA)
RGB格式: R1, G1, B1, R2, G2, B2, ..., Rn, Gn, Bn
RGBA格式: R1, G1, B1, A1, R2, G2, B2, A2, ..., Rn, Gn, Bn, An

像素按行优先顺序排列(从左到右，从上到下)

解析器使用指南

NeleColor可以打开.nelecolor文件并预览图像内容，支持以下功能：

  • 打开.nelecolor文件并显示图像预览
  • 查看文件信息(分辨率、原始格式)
  • 旋转图像
  • 导出为原始格式的图像文件

操作步骤

  1. 点击"文件"菜单 → "打开"，选择.nelecolor文件
  2. 预览图像并查看文件信息
  3. 使用旋转按钮调整图像方向(可选)
  4. 点击"文件"菜单 → "导出图片"，保存为原始格式
注意： 转换大尺寸图像可能需要较多内存，建议分批处理超大图像。

转换器使用指南

NeleColor转换器可以将常见图像格式转换为.nelecolor格式：

  • 支持PNG、JPEG、BMP等常见格式
  • 预览图像内容
  • 转换为.nelecolor格式并保存
  • 选择RGB或RGBA编码格式

操作步骤

  1. 点击"导入图片"按钮，选择要转换的图像文件
  2. 预览图像内容
  3. 选择编码格式(RGB或RGBA)
  4. 点击"导出.nelecolor文件"按钮，选择保存位置
  5. 转换完成后会显示成功消息

错误原因

常见错误代码

错误代码 原因 解决方案
ERR_HEADER_INVALID 文件头格式不正确 检查文件头是否符合"宽度x高度.扩展名"格式
ERR_PIXEL_COUNT 像素数量不匹配 确认图像分辨率与文件头声明一致
ERR_COLOR_RANGE 颜色值超出0-255范围 检查图像数据是否损坏
ERR_ENCODING 不支持的编码格式 确保只使用rgb或rgba编码

UTF-8解码错误

当出现类似 'utf-8' codec can't decode byte 0xda in position 10: invalid continuation byte 的错误时，通常是因为：

  • 文件头不是有效的UTF-8编码
  • 文件可能已损坏或被修改
  • 文件可能不是真正的.nelecolor格式文件

解决方案

  1. 确认文件是有效的.nelecolor格式
  2. 检查文件是否完整未被损坏
  3. 尝试用原始转换器重新生成文件

解析.nelecolor文件

Python示例代码 
# Python示例代码
with open("image.nelecolor", "rb") as f:
    # 读取文件头
    header = b""
    while True:
        byte = f.read(1)
        if byte == b"\n":
            break
        header += byte
    
    # 解析分辨率
    header_str = header.decode("utf-8")
    
    # 检查编码格式
    if ":" in header_str:
        header_part, encoding = header_str.split(":", 1)
        encoding = encoding.lower()
    else:
        header_part = header_str
        encoding = "rgb"  # 默认RGB格式
    
    resolution_part, ext = header_part.split(".", 1)
    width, height = map(int, resolution_part.split("x"))
    
    # 读取像素数据
    pixel_data = f.read()
    
    # 根据编码创建图像
    if encoding == "rgb":
        img = Image.new("RGB", (width, height))
        pixels = img.load()
        
        index = 0
        for y in range(height):
            for x in range(width):
                r, g, b = pixel_data[index], pixel_data[index+1], pixel_data[index+2]
                pixels[x, y] = (r, g, b)
                index += 3
    else:  # rgba
        img = Image.new("RGBA", (width, height))
        pixels = img.load()
        
        index = 0
        for y in range(height):
            for x in range(width):
                r, g, b, a = pixel_data[index], pixel_data[index+1], pixel_data[index+2], pixel_data[index+3]
                pixels[x, y] = (r, g, b, a)
                index += 4

常见问题

Q:为什么我的.nelecolor文件无法打开？

A:请检查文件是否符合.nelecolor格式规范，特别是文件头格式是否正确。

Q:转换后的图像颜色不正确

A:确保原始图像是RGB格式，某些特殊格式(如带透明通道的PNG)可能需要先转换为RGB。

Q:支持哪些图像格式？

A:支持所有Pillow库支持的格式，包括PNG、JPEG、BMP、GIF等。
