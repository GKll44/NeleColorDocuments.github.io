概述

NeleColor 是一套用于处理.nelecolor图像格式的工具集，包含两个主要组件：

  • NeleColor - 用于查看.nelecolor格式文件
  • NeleColor 转换器 - 用于将常见图像格式转换为.nelecolor格式

这两个工具都基于Python开发，使用Tkinter构建图形界面，Pillow库处理图像数据。

.nelecolor 格式规范

.nelecolor 是一种简单的二进制图像格式，由两部分组成：

  1. 文本头 - 包含分辨率信息和原始格式
  2. 像素数据 - 连续的RGB值二进制数据

文件头格式

文件头是一个UTF-8编码的字符串，格式为：宽度x高度.扩展名

例如：256x256.png 表示这是一个256x256像素的图像，原始格式为PNG

文件头以换行符(\n)结束

像素数据格式

像素数据是连续的二进制数据，每个像素由3个字节表示(RGB)：

R1, G1, B1, R2, G2, B2, ..., Rn, Gn, Bn

像素按行优先顺序排列(从左到右，从上到下)

解析器使用指南

NeleColor可以打开.nelecolor文件并预览图像内容，支持以下功能：

  • 打开.nelecolor文件并显示图像预览
  • 查看文件信息(分辨率、原始格式)
  • 旋转图像
  • 导出为原始格式的图像文件

操作步骤

  1. 点击"文件"菜单 → "打开"，选择.nelecolor文件
  2. 预览图像并查看文件信息
  3. 使用旋转按钮调整图像方向(可选)
  4. 点击"文件"菜单 → "导出图片"，保存为原始格式

转换器使用指南

NeleColor转换器可以将常见图像格式转换为.nelecolor格式：

  • 支持PNG、JPEG、BMP等常见格式
  • 预览图像内容
  • 转换为.nelecolor格式并保存

操作步骤

  1. 点击"导入图片"按钮，选择要转换的图像文件
  2. 预览图像内容
  3. 点击"导出.nelecolor文件"按钮，选择保存位置
  4. 转换完成后会显示成功消息

错误原因

UTF-8解码错误

当出现类似 'utf-8' codec can't decode byte 0xda in position 10: invalid continuation byte 的错误时，通常是因为：

  • 文件头不是有效的UTF-8编码
  • 文件可能已损坏或被修改
  • 文件可能不是真正的.nelecolor格式文件

解决方案

  1. 确认文件是有效的.nelecolor格式
  2. 检查文件是否完整未被损坏
  3. 尝试用原始转换器重新生成文件

其他常见错误

无效文件头：文件头不符合"宽度x高度.扩展名"的格式要求

像素数量不符：实际像素数据与文件头声明的分辨率不匹配

几乎不可能的错误

颜色值越界：RGB值不在0-255范围内

开发指南

NeleColor是开源项目，欢迎开发者贡献代码或基于此开发自己的工具。

依赖：

  • Python 3.6+
  • Pillow (PIL) 库
  • Tkinter (通常随Python一起安装)

解析.nelecolor文件

Python示例代码 
# Python示例代码
with open("image.nelecolor", "rb") as f:
    # 读取文件头
    header = b""
    while True:
        byte = f.read(1)
        if byte == b"\n":
            break
        header += byte
    
    # 解析分辨率
    header_str = header.decode("utf-8")
    resolution_part, ext = header_str.split(".", 1)
    width, height = map(int, resolution_part.split("x"))
    
    # 读取像素数据
    pixel_data = f.read()
    img = Image.new("RGB", (width, height))
    pixels = img.load()
    
    index = 0
    for y in range(height):
        for x in range(width):
            r, g, b = pixel_data[index], pixel_data[index+1], pixel_data[index+2]
            pixels[x, y] = (r, g, b)
            index += 3

常见问题

Q:为什么我的.nelecolor文件无法打开？

A:请检查文件是否符合.nelecolor格式规范，特别是文件头格式是否正确。

Q:转换后的图像颜色不正确

A:确保原始图像是RGB格式，某些特殊格式(如带透明通道的PNG)可能需要先转换为RGB。

Q:如何批量转换图像？

A:当前版本不支持批量转换，但可以通过编写脚本调用转换器核心功能实现。
